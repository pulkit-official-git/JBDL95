1. Modernization & Architectural Scope

This report details the architectural transformation of the Digital Library Management System from legacy HTTP Basic session-based authentication to a modern, decoupled Stateless JWT (JSON Web Token) Security Model and a state-of-the-art React Single Page Application (SPA).

Key Engineering Deliverables
  • Stateless Security Pipeline: Replaced server-side HTTP sessions with HMAC-SHA256 signed JWT tokens (24h TTL) and automated Bearer token request validation.
  • Role-Based Access Control (RBAC): Gated route protection separating Student functions from Admin operations with custom 401/403 handlers and CORS support.
  • Interactive React + Vite Frontend: Built a glassmorphic dashboard in frontend/ featuring dynamic quota tracking, 1-click book returns with fine calculations, and multi-role portals.

2. JWT Security Architecture & Pipeline

The security subsystem utilizes the JJWT (Java JSON Web Token) 0.12.6 library suite, configured to operate in a fully stateless mode.

Figure 2.1: Stateless JWT Authentication & Security Context Injection Pipeline

2.1 Component Responsibilities

Component File Location Core Responsibility
JwtUtil configs/JwtUtil.java Generates HMAC-SHA256 tokens with claims (sub, roles), extracts claims, checks expiration, and validates tokens.
JwtAuthenticationFilter configs/JwtAuthenticationFilter.java OncePerRequestFilter intercepting Authorization: Bearer <token>, resolving UserDetails and setting SecurityContextHolder.
JwtAuthEntryPoint configs/JwtAuthenticationEntryPoint.java Catches unauthenticated requests and returns standard HTTP 401 JSON error format.
GlobalExceptionHandler configs/GlobalExceptionHandler.java Catches validation errors, duplicate username/email conflicts, and runtime exceptions.
SecurityConfig configs/SecurityConfig.java Stateless session policy, CORS policy, and role route gating (STUDENT vs ADMIN).

3. React Single Page Application (SPA) Architecture

The frontend is developed in frontend/ using Vite 5 and React 18. It features a custom, responsive design system using Vanilla CSS with glassmorphism, responsive data tables, modal dialogs, and real-time toast alerts.

Figure 3.1: React Frontend Component Hierarchy & Service Integration

3.1 Key Frontend Features

  • Universal Auth Modal (3 Tabs): Seamlessly switch between Sign In, Student Sign Up, and Admin Sign Up.
  • Live Quota Tracker: Visualizes student quota (3 books max), 15-day borrowing window, and ₹100/day overdue fine rate.
  • 1-Click Book Return: Calls POST /txn/initiate?bookId={id}&transactionType=RETURN, displays generated UUID transaction code, and updates loan tables in real-time.
  • Admin Control Center: Multi-field book & author creator with genre dropdowns, student record auditor by ID, and co-admin generator.
